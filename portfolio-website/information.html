Featured project: Campus Event Planner

Campus Event Planner is a small web application concept that helps university societies publish their events in one place. Students can see what is happening this week, check the venue and time, and find the right society contact.

I designed the page layout, wrote the semantic HTML and styled it with a consistent color scheme. The design focuses on readable text, clear headings and navigation that works on both desktop and mobile screens.
